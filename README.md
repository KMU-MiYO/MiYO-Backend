## MiYO Backend 🗺️

> 우리 동네를 더 나은 곳으로 만들기 위한 시민 참여형 플랫폼 - Backend API Server

MiYO Backend는 위치 기반 시민 참여 플랫폼의 핵심 API 서버입니다. Spring Boot 기반의 RESTful API를 제공하며, AI 이미지 생성, 실시간 위치 기반 서비스, 챌린지 시스템 등을 지원합니다. Kubernetes 기반의 MSA 아키텍처로 구성되어 안정적이고 확장 가능한 서비스를 제공합니다.

## ✨ 주요 기능

### 🔐 인증 및 사용자 관리
- **JWT 기반 인증**: Access Token 및 Refresh Token을 활용한 안전한 인증
- **사용자 프로필 관리**: 닉네임, 프로필 이미지, 활동 내역 관리

### 📍 위치 기반 제안 시스템
- **공간 데이터 처리**: MySQL Spatial Data Types를 활용한 지리 정보 저장
- **반경 기반 검색**: 사용자 위치 기준 반경 내 제안글 조회
- **카테고리별 필터링**: 7가지 카테고리(자연, 문화, 교통, 주거, 상권, 야간, 환경)
- **다중 정렬 옵션**: 인기순(공감수), 최신순, 거리순 정렬 지원
- **실시간 Top3 집계**: Redis 캐싱을 활용한 인기 제안글 순위 시스템

### 🎨 AI 이미지 생성 서비스
- **Stable Diffusion API 연동**: 텍스트 기반 이미지 생성
- **Image-to-Image 변환**: 기존 이미지 기반 새로운 이미지 생성
- **이미지 저장소 관리**: Naver Cloud Object Storage 연동
- **생성 이력 관리**: 사용자별 이미지 생성 이력 및 재사용 기능

### 🏆 챌린지 시스템
- **주간 미션 관리**: 스케줄링 기반 자동 미션 생성
- **지자체 협업 챌린지**: 관리자 전용 챌린지 생성 API
- **참여 및 보상 시스템**: 챌린지 완료 시 포인트 지급
- **실시간 랭킹**: Redis Sorted Set을 활용한 실시간 순위 집계

### 💬 커뮤니티 기능
- **제안글 CRUD**: 이미지, 위치, 카테고리 정보를 포함한 제안글 관리
- **공감 시스템**: 중복 방지 로직이 적용된 공감 기능
- **댓글 및 대댓글**: 계층형 댓글 구조 지원

### 📊 관리자 기능
- **대시보드**: 사용자, 제안글, 챌린지 통계 조회
- **콘텐츠 모더레이션**: 신고된 콘텐츠 검토 및 처리
- **공지사항 관리**: 앱 내 공지사항 작성 및 푸시 알림
- **데이터 분석**: 지역별, 카테고리별 통계 분석
